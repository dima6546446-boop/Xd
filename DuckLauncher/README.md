# 🦆 Duck Launcher

Лаунчер Minecraft **1.21.4** с уже установленным **Duck Visual**. Скачал `Duck Launcher.exe` → запустил → вошёл → **ИГРАТЬ**.

## Что делает лаунчер

При первом нажатии «Играть» он сам скачивает всё нужное (≈ 600 МБ, один раз):

| Что | Откуда |
|---|---|
| Java 21 (Eclipse Temurin JRE) | api.adoptium.net |
| Minecraft 1.21.4: клиент, библиотеки, ресурсы | серверы Mojang |
| Fabric Loader (последний стабильный) | meta.fabricmc.net |
| Fabric API 0.119.4 | maven.fabricmc.net |
| Sodium 0.6.13 (можно выключить) | Modrinth |
| Duck Visual | вшит прямо в .exe |
| authlib-injector (только для Ely.by) | authlib-injector.yushi.moe |

Все файлы проверяются по контрольным суммам. Следующие запуски — сразу.

Всё хранится в `%APPDATA%\.ducklauncher` (игра — в `minecraft`, моды — в `minecraft\mods`, туда можно добавлять свои моды для 1.21.4 Fabric).

## Вход

- **Без лицензии** — просто ник (латиница/цифры/_ , 3–16 символов). Для серверов с оффлайн-режимом.
- **Ely.by** — логин/e-mail и пароль (при 2FA: `пароль:код`). Скин и плащ с Ely.by, вход на серверы с поддержкой Ely.by через authlib-injector.

Пароль нигде не сохраняется — хранится только токен входа в `launcher.json`.

## Настройки

Память для игры, Sodium вкл/выкл, закрывать ли лаунчер при запуске, свои аргументы Java, кнопки «Папка игры / Моды / Скриншоты / Логи».

## Требования

Windows 10/11 x64. Окно лаунчера использует **Microsoft Edge WebView2** — он встроен в Windows 11; на Windows 10 лаунчер сам предложит его скачать, если нет.

## Сборка

```sh
./build.sh        # нужен Go 1.24+
```

Результат: `dist/Duck Launcher.exe`. Есть консольный режим (и Linux-сборка) для проверки:
`ducklauncher -cli -name Nickname`.
