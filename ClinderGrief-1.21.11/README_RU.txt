2. ТРЕБОВАНИЯ
---------------------------------------------------------------------
  * Windows 10 или 11, 64-бит (для start.bat). Linux/macOS — start.sh.
  * Оперативная память: сервер по умолчанию берёт до 4 ГБ (+ до 512 МБ
    прокси Velocity), на компьютере должно быть хотя бы 8 ГБ. Изменить: строки MIN_RAM / MAX_RAM в начале
    start.bat (открыть «Блокнотом»).
  * Java 21+ (64-бит). Если её нет — start.bat предложит скачать
    Eclipse Temurin JRE 21 (adoptium.net) в папку runtime сборки,
    с проверкой контрольной суммы SHA-256. В систему ничего не ставится.
  * Интернет при первом запуске: Paper скачивает файлы игры с серверов
    Mojang и библиотеки (≈150 МБ), плагины — свои библиотеки.
  * Свободное место: от 2 ГБ (мир растёт по мере игры).

3. УСТАНОВКА И ПЕРВЫЙ ЗАПУСК
---------------------------------------------------------------------
 1) Распакуйте архив целиком, например в C:\ClinderGrief
    (лучше путь без кириллицы и пробелов — так надёжнее).
    Сборка бывает в двух вариантах:
      ClinderGrief-Paper-1.21.11-full.zip (~140 МБ) — всё, включая ядро и плагины;
      ClinderGrief-Paper-1.21.11-lite.zip (~11 МБ)  — без jar-файлов: при первом
        запуске start.bat сам скачает ядро Paper и плагины (~110 МБ) с
        официальных адресов (PaperMC, Modrinth, GitHub) и сверит SHA-256.
    После этого обе версии одинаковы.
 2) Дважды щёлкните start.bat.
 3) Если Java 21 не найдена — нажмите Y, чтобы скачать её автоматически
    (или установите вручную: https://adoptium.net/temurin/releases/?version=21).
 4) Скрипт покажет ссылку на EULA Minecraft (https://aka.ms/MinecraftEULA).
    Прочитайте и нажмите Y, если принимаете. Это делает ТОЛЬКО владелец
    сервера — в архиве EULA намеренно не принята (eula=false).
 5) start.bat откроет ВТОРОЕ окно «ClinderGrief Velocity» — это прокси с
    регистрацией. Не закрывайте его: без него на сервер не зайти.
    При самом первом запуске создаётся уникальный секретный ключ связи
    прокси и сервера (velocity\forwarding.secret).
 6) Первый запуск длится 1–3 минуты (загрузка файлов, подготовка плагинов).
    Сервер готов, когда в основном окне появится строка:
        Done (…s)! For help, type "help"
 7) Остановить: в основном окне введите  stop  и нажмите Enter, затем в
    окне Velocity введите  end . Не закрывайте окна крестиком — мир может
    не сохраниться. После остановки скрипт предложит: R — перезапустить
    (прокси при этом продолжает работать), Q — выйти.

Windows может спросить разрешение для Java в брандмауэре — разрешите
доступ в частных сетях (и в общедоступных, если друзья подключаются
через интернет).

4. ПОДКЛЮЧЕНИЕ К СЕРВЕРУ
---------------------------------------------------------------------
  * С этого же компьютера: в Minecraft 1.21.11 → Сетевая игра →
    Добавить сервер → адрес  localhost
  * В локальной сети: адрес — локальный IP компьютера (команда ipconfig,
    строка IPv4, например 192.168.1.10).
  * Через интернет: нужен проброс порта 25565 (TCP) на роутере и внешний
    («белый») IP либо VPN/туннель. Подробно — MANUAL_STEPS_RU.txt.

Как устроено подключение:
  Игрок → Velocity (порт 25565, все сетевые адреса) → регистрация/вход →
  сервер выживания Paper (127.0.0.1:25566 — доступен ТОЛЬКО с этого
  компьютера, напрямую в обход регистрации на него не зайти).
  Пробрасывать на роутере нужно только 25565.

Регистрация (LimboAuth):
  * Новый игрок попадает в пустой «лимбо»-мир и видит подсказку:
        /reg <пароль> <пароль ещё раз>     (пароль от 6 символов)
  * Затем при каждом входе:  /login <пароль>
    С того же IP в течение часа после входа пароль повторно не спрашивается.
  * /changepassword <старый> <новый> — сменить пароль
  * /2fa enable <пароль> — двухфакторная защита (Google Authenticator и т.п.)
  * /unregister <пароль> confirm — удалить свою регистрацию
  * Игроки с ЛИЦЕНЗИЕЙ входят автоматически, без пароля. Ник, который
    принадлежит лицензионному аккаунту, с пиратского клиента занять нельзя
    (защита от кражи ников).
  * На один IP — не больше 3 регистраций.
  * Админ (в окне Velocity): forceunregister Ник — сбросить регистрацию,
    forcechangepassword Ник пароль — сменить пароль игроку.
  Режим сервера — online-mode=false на Velocity (пускает и лицензию, и
  пиратские клиенты). ВАЖНО: см. MANUAL_STEPS_RU.txt, раздел про EULA —
  как оставить вход только для лицензии.
Версия клиента — 1.21.11.

5. ВЫДАЧА ПРАВ И ПРИВИЛЕГИЙ
---------------------------------------------------------------------
Права выдаются через LuckPerms. Команды вводятся в консоль сервера
(окно start.bat) без «/» или в игре с «/» (если у вас уже есть права).

Сделать себя администратором (обязательно после первого входа):
    lp user ВашНик parent set admin

Группы (уже созданы и настроены):
  Группа     Префикс        Кто это
  default    (серый ник)    все игроки
  vip        [VIP]          привилегия 1 (только косметика)
  premium    [Premium]      привилегия 2
  elite      [Элита]        привилегия 3
  legend     [Легенда]      привилегия 4
  titan      [Титан]        привилегия 5
  imperator  [Император]    привилегия 6
  god        [БОГ]          привилегия 7 (высшая)
  helper    [Хелпер]       младший модератор: мут, кик, тюрьма,
                           временный бан (до 7 дней), просмотр журнала
  moder     [Модератор]    + бан, ваниш, invsee, откат CoreProtect,
                           телепорт, полёт, удаление приватов
  admin     [Админ]        все права (*)

Примеры:
    lp user Ник parent set moder          — назначить модератором
    lp user Ник parent add vip            — выдать VIP навсегда
    lp user Ник parent addtemp vip 30d    — выдать VIP на 30 дней
    lp user Ник parent remove vip         — забрать VIP
    lp user Ник info                      — посмотреть группы игрока
    lp editor                             — удобный веб-редактор прав

Что дают привилегии (каждая включает всё из предыдущих; только косметика):
  VIP:       префикс, цветной чат (&a, &b …), /hat, титул [★],
             частицы: 1 эффект (сердца, ноты, искры)
  Premium:   + /nick с цветами, жирный/курсив в чате, /ptime, /pweather,
             титул [Кибер], частицы: 2 эффекта (огонь, магия, облака)
  Элита:     + HEX-цвета в чате и нике, цветные таблички, титул [Тень],
             ВСЕ эффекты и стили частиц, 3 одновременно
  Легенда:   + объявление о входе на сервер, титул [Пламя], 4 частицы
  Титан:     + эффектное объявление о входе, титул [☠ Демон], 5 частиц
             и 1 стационарный эффект частиц
  Император: + объявление со звуком, «магический» ник, титул [♛ Корона],
             6 частиц и 3 стационарных эффекта
  БОГ:       + громовое объявление о входе, титул [⚡ Божество],
             8 частиц и 5 стационарных эффектов
Привилегии НЕ дают предметов, денег, полёта, бессмертия, лишних приватов
и других игровых преимуществ — продажа таких преимуществ запрещена
Правилами использования Minecraft (Minecraft Usage Guidelines / EULA).

Все команды создания групп сохранены в файле
plugins/LuckPerms/ClinderGrief-luckperms-setup.txt — по нему можно
восстановить группы в чистой базе.

6. ЧТО УМЕЕТ СЕРВЕР (ДЛЯ ИГРОКОВ)
---------------------------------------------------------------------
Спавн — большой летающий остров (радиус 48 блоков) над точкой 0,0:
двухъярусный фонтан, площадь с голограммами-топами, кольцевая аллея,
4 павильона и 5 площадок с NPC, огненные врата на выходах, светлячки,
вишни. На севере в небе — гигантская объёмная надпись ClinderGrief
(152×19 блоков). Рядом — острова «Шахта» (/warp mine) и «PvP-Арена»
(/warp arena). Новички появляются на спавне
и получают стартовый набор (каменные инструменты, еда, факелы, брёвна,
золотая лопата для привата и палка для просмотра приватов).
На спавне нельзя ломать/строить, PvP, урон от падения и мобы отключены.

NPC на спавне (нажмите на жителя):
  Торговец   → магазин сервера (/shop)
  Скупщик    → скупщик ресурсов (/buyer)
  Привилегии → описание привилегий (/donate)
  Гид        → главное меню (/menu)
  Аукцион    → /ah        Кланы → /clan        Ивенты → /event
  Кейсы (светящийся Эллей) → /cases
  Шахта      → /warp mine                      Арена  → /warp arena

Кейсы /cases (как на FunTime/HolyWorld):
  Ключи виртуальные — хранятся на аккаунте, их не украсть и не потерять.
  ЛКМ по кейсу — открыть (анимация прокрутки), ПКМ — посмотреть всё
  содержимое с шансами выпадения в процентах.
  Обычный кейс — деньги (300–1500$), ресурсы, яблоки, жемчуг, редко —
    зачарованное яблоко, незеритовый лом, ключ редкого/донатного кейса.
    Ключ: за каждое ежедневное задание /quests.
  Редкий кейс — 3000$, алмазы, тотем, элитры, маяк, ключ донатного кейса.
    Ключ: за все 3 задания дня и за каждые 7 дней серии /daily.
  Донатный кейс — ТОЛЬКО косметика: временные привилегии (VIP 7 дней …
    БОГ 1 день — а они сами только косметические), эксклюзивные титулы
    [✹ Феникс], [☁ Призрак], [♔ Король кейсов], частицы «Дыхание дракона».
    Если титул/частицы уже есть — вместо них выдаются ключи редкого кейса.
    Ключ: можно продавать через Tebex (MANUAL_STEPS_RU.txt), выпадает и
    бесплатно из обычного (0,5%) и редкого (4%) кейсов.
  Шансы выводятся автоматически из «весов» в plugins/ClinderCore/config.yml
  (раздел cases) — правьте там, затем cg reload.

Ежедневные задания /quests: каждый день 3 случайных задания из 12
(добыть руду, нарубить брёвен, собрать урожай, убить мобов, поймать
рыбу). Награда — деньги и ключ обычного кейса, за все три — ключ
редкого. Блоки, поставленные игроками, и незрелый урожай не считаются.

Аукцион /ah (как на FunTime/ReallyWorld):
  /ah                 — открыть аукцион (Shift+ЛКМ — купить, ПКМ — снять свой)
  /ah sell <цена>     — выставить предмет из руки (до 7 лотов, срок 48 ч)
  /ah storage         — забрать снятые и просроченные лоты
  С продажи удерживается налог 5% (сжигание денег в экономике).

Кланы /clan:
  /clan create <тег> [название] — создать клан (5000$), тег 2–6 символов
  /clan invite <ник>, /clan accept, /clan deny, /clan kick <ник>
  /clan info [тег], /clan top, /clan leave, /clan disband confirm
  /cc <текст> — клановый чат. Тег клана виден в чате и TAB,
  соклановцы не могут ранить друг друга, топ кланов — по убийствам.

Ивент «Мистический сундук» (аирдроп): раз в час (если на сервере 2+
игрока) в 300–1500 блоках от спавна появляется сундук с лутом —
координаты в чате и в боссбаре. Через 2 минуты он открывается, через
10 минут исчезает. /event — где сундук или сколько ждать следующего.

Режим боя: после удара по игроку оба на 15 секунд «в бою» (боссбар
с таймером). В бою нельзя телепортироваться (/spawn, /home, /tpa, /tpr,
/warp, /back), открыть аукцион и меню. Вышел из игры в бою — погиб.

Шахта (/warp mine): общая шахта 21×21×15 блоков руды, полностью
обновляется каждые 10 минут (за 30 секунд — предупреждение).
PvP-арена (/warp arena): единственное место у спавна, где включено PvP.

Основные команды:
  /menu                 главное меню (всё ниже доступно и через него)
  /daily                ежедневная награда: 100$ → 750$ за 7 дней серии
                        подряд + 1000$ и ключ редкого кейса за каждые 7 дней
  /cases, /quests       кейсы и ежедневные задания
  /tags                 титул после ника (за часы в игре или привилегию)
  /pp                   частицы (для привилегий)
  /bounty Ник сумма     назначить награду за голову (получит убийца),
  /bounty list          список наград
  /top money|playtime|kills  топы игроков (они же — голограммы у фонтана)
  /report Ник причина   пожаловаться модераторам
  /links                ссылки на соцсети и сайт
  /shop  /buyer         магазин сервера / скупщик
  /tpr  (или /rtp)      случайная телепортация в дикий мир (300–3000 блоков)
  /spawn                на спавн
  /sethome [имя], /home [имя], /delhome   — до 3 домов
  /tpa Ник, /tpahere Ник, /tpaccept, /tpdeny
  /back                 вернуться на прошлое место (и после смерти)
  /balance, /baltop, /pay Ник сумма
  /sell hand, /sell <предмет>, /worth   — продажа скупщику и цены
  /kit start (один раз), /kit food (раз в сутки)
  /msg Ник текст, /r, /mail, /ignore
  /rules, /helpop текст (вызвать модератора)

Каждые 30 минут активной игры (не AFK) — +75$.
Каждые 5 минут в чате — подсказка-объявление.
Нецензурные слова в чате автоматически заменяются на ***.

Экономика: стартовый баланс 500$. Деньги зарабатываются продажей
ресурсов скупщику и торговлей с игроками. Цены продажи всегда ниже цен
покупки — бесконечно перепродавать нельзя.

Приваты (GriefPrevention):
  * Первый сундук автоматически приватит небольшую область вокруг.
  * Золотая лопата: ПКМ по одному углу, затем по противоположному.
  * Палка (ПКМ) показывает границы приватов.
  * Старт — 400 блоков привата, +150 за каждый час игры.
  * /trust Ник, /untrust Ник, /claimslist, /abandonclaim,
    /buyclaimblocks кол-во (5$ за блок), /sellclaimblocks.

Магазины игроков (QuickShop): поставьте сундук, ударьте его (ЛКМ)
предметом-товаром, введите в чат цену за 1 шт. Покупатель нажимает на
сундук и вводит количество. /qs sell, /qs buy, /qs price, /qs remove.

10. ЧТО ПРОВЕРЕНО ПРИ СБОРКЕ, ОГРАНИЧЕНИЯ
---------------------------------------------------------------------
Сборка запускалась на Linux (OpenJDK 21) с теми же параметрами JVM,
что в start.bat (через start.sh). Проверено:
  * все 16 плагинов и прокси Velocity с LimboAPI/LimboAuth загружаются
    без ошибок (ERROR в логе нет);
  * тестовые боты (клиент mineflayer, протокол 1.21.11) подключались и
    проверяли: точку спавна и стартовый набор, баланс, меню, покупку в
    магазине, продажу скупщику, NPC, TAB, защиту спавна, /tpr, /sethome,
    /home, авто-приват сундука, создание магазина QuickShop, мут, тюрьму,
    формат чата и префиксы, отказ в доступе к админ-командам;
  * ClinderCore 1.1: аукцион (выставление, покупка со списанием денег
    и налогом, снятие лота), кланы (создание, приглашение, вступление,
    тег в чате, клановый чат), мистический сундук (появление, блокировка
    до отсчёта, открытие), режим боя (боссбар, запрет /spawn), шахта;
  * ClinderCore: /daily (серия и повтор), /tags (выбор, блокировка по
    привилегии), фильтр мата (сохраняет обычные слова вроде «употребляю»),
    /report с откатом 60 с, /bounty (списание, выплата убийце, блокировка
    при одинаковом IP), /top, /links, объявление о входе ранга «Бог»;
  * донат-ранг «Бог»: префикс, титул, меню частиц, отсутствие /fly;
  * ClinderCore 1.2 и прокси (боты заходили через Velocity на 25565):
    регистрация /reg нового ника, повторный вход, кик ника лицензионного
    аккаунта с пиратского клиента («You are not logged into your Minecraft
    account»); /cases — выдача ключей из консоли, просмотр шансов,
    открытие обычного и донатного кейса (выпал титул, он появился в /tags),
    сообщение об отсутствии ключей; /quests — задание «Нарубить 64 бревна»
    засчиталось с наградой, меню показывает прогресс;
  * ClinderAC (бот имитировал читы): полёт — обнаружен, откат на землю,
    уведомление; спидхак ~12 бл/с — обнаружен; подмена «на земле» —
    обнаружена; удары с 4,5 блока — обнаружены, отменены; автокликер
    26 CPS — обнаружен. Обычная ходьба, честные удары с 2 блоков и рубка 64
    брёвен алмазным топором ложных срабатываний не дали.
  * все файлы плагинов скачаны с Modrinth/GitHub, контрольные суммы
    совпали с опубликованными (SOURCES.txt).
Античит эвристический (как любой самописный): он не заменяет
Grim/Vulcan и может давать ложные срабатывания при сильном лаге —
поэтому по умолчанию он только откатывает и уведомляет, а кикает лишь
при большом накопленном VL; автоматических банов нет (punish-command
пустой). Первые дни посмотрите violations.log и при необходимости
поднимите пороги в plugins/ClinderAC/config.yml.

Ограничения проверки:
  * start.bat не запускался на настоящей Windows (её не было в среде
    сборки). Логика скрипта (поиск Java в runtime\, разбор версии,
    проверка 64-bit, проверка EULA, команда запуска) проверена через
    cmd.exe из Wine; сама Java под Wine не работает, поэтому полный запуск
    именно через start.bat на Windows — пункт для проверки владельцем.
  * scripts\install-java.ps1 и scripts\download-files.ps1 проверены в
    PowerShell 7.4 (Linux): Java 21 скачалась и распаковалась, контрольная
    сумма совпала; ядро и плагины докачались, повреждённый файл был
    перекачан. В Windows PowerShell 5.1 (встроен в Windows) скрипты не
    запускались — используются только его стандартные команды.
  * Облегчённый архив проверен: распакован в пустую папку, start.sh
    скачал все 17 файлов, сервер запустился со всеми 15 плагинами.
  * Вход с настоящего лицензионного клиента не проверялся.
  * Запуск второго окна Velocity из start.bat на настоящей Windows не
    проверялся (на Linux start.sh запускает прокси и сервер — проверено);
    scripts\new-secret.ps1 проверен в PowerShell 7.4.
