=====================================================================
  ClinderGrief — ЧТО ВЛАДЕЛЕЦ ДОЛЖЕН СДЕЛАТЬ ВРУЧНУЮ
=====================================================================
Сборка запускается «из коробки», но эти шаги может выполнить только
владелец сервера. Отмечайте выполненное.

ОБЯЗАТЕЛЬНО
---------------------------------------------------------------------
[ ] 1. Принять EULA Minecraft.
       Прочитайте https://aka.ms/MinecraftEULA. При первом запуске
       start.bat спросит согласие (Y) и сам запишет eula=true в eula.txt.
       Вручную: откройте eula.txt и замените eula=false на eula=true.
       В архиве EULA намеренно НЕ принята — это решение владельца.

[ ] 2. Java 21+ (64-бит).
       start.bat найдёт установленную Java или предложит скачать
       Temurin JRE 21 в папку runtime (нужен интернет). Если автоматическая
       загрузка не сработала — установите вручную:
       https://adoptium.net/temurin/releases/?version=21 (Windows x64, JRE, .msi)

[ ] 3. Назначить себя администратором — в консоли сервера:
           lp user ВашНик parent set admin
       Выдавать «op» не нужно (группа admin уже имеет все права).

[ ] 4. Настроить доступ из интернета (если играете не только в локальной сети):
       a) Узнайте локальный IP компьютера: команда ipconfig → «IPv4-адрес».
          Желательно закрепить его за компьютером в настройках роутера (DHCP-резерв).
       b) В роутере пробросьте порт 25565 (TCP) на этот IP
          («Перенаправление портов» / «Port Forwarding» / «Виртуальные серверы»).
       c) Разрешите Java в брандмауэре Windows (запрос появится при первом
          запуске; иначе: Брандмауэр → Разрешение взаимодействия с приложением).
       d) Игрокам сообщите внешний IP (например, на 2ip.ru). Если провайдер
          даёт «серый» IP (CGNAT), проброс не поможет — нужен «белый» IP у
          провайдера, VPS-хостинг или сервис-туннель.
       e) По желанию — домен и SRV-запись _minecraft._tcp.
       Пробрасывать нужно ТОЛЬКО 25565 — это порт прокси Velocity.
       Порт 25566 (сам сервер Paper) наружу НЕ открывайте: в
       server.properties стоит server-ip=127.0.0.1, так и оставьте —
       иначе можно зайти в обход регистрации.
       Брандмауэр спросит разрешение для Java дважды (Velocity и Paper) —
       разрешите оба.

[ ] 5. Объём памяти. В start.bat (открыть «Блокнотом») строки
       set "MIN_RAM=2G" и set "MAX_RAM=4G". Не выделяйте больше половины
       оперативной памяти компьютера.

ДОНАТ (ПРИЁМ ПЛАТЕЖЕЙ) — НЕ НАСТРОЕН, ТРЕБУЕТ ВАШИХ ДЕЙСТВИЙ
---------------------------------------------------------------------
В сборке есть группы vip/premium/elite и меню /donate с описанием, но
приём денег НЕ подключён: для этого нужен аккаунт в платёжной платформе,
договор и ключи — их нельзя получить за вас.

[ ] 6. Выберите платформу приёма платежей. Пример — Tebex (официальный
       партнёр Minecraft для монетизации серверов):
       a) Зарегистрируйтесь на https://www.tebex.io/ и создайте магазин
          (Minecraft: Java Edition). Пройдите проверку и подключите выплаты.
       b) Скопируйте optional-plugins/tebex-bukkit-2.4.2-*.jar в папку plugins
          и перезапустите сервер.
       c) В консоли сервера: tebex secret <ВАШ_СЕКРЕТНЫЙ_КЛЮЧ>
          (ключ — в панели Tebex: Integrations → Game Servers).
       d) В пакетах Tebex укажите команды выдачи, например:
             lp user {username} parent addtemp vip 30d
             lp user {username} parent addtemp premium 30d
             lp user {username} parent addtemp elite 30d
             (и так же legend, titan, imperator, god)
          Ключи донатного кейса:
             cases give {username} donate 1
          (команда работает из консоли и игроку можно не быть онлайн —
          ключ сохранится на аккаунте).
       Можно использовать и другие сервисы — тогда следуйте их инструкции.
       Плагин Tebex в сборке не проверялся с реальным ключом.

[ ] 7. Укажите ссылки на магазин и соцсети:
       plugins/ClinderCore/config.yml, раздел links (команда /links) →
       замените УКАЖИТЕ-ССЫЛКУ, затем в консоли: cg reload.
       Также — ссылку в меню привилегий:
       plugins/DeluxeMenus/gui_menus/donate.yml — замените текст
       УКАЖИТЕ-ССЫЛКУ-НА-ВАШ-МАГАЗИН на адрес магазина, затем в консоли: dm reload

[ ] 8. Правила монетизации. Продавать можно только то, что не даёт игрового
       преимущества (косметика, префиксы, цвета) — так настроены группы
       vip/premium/elite. Не добавляйте в донат предметы, ресурсы, деньги,
       /fly, /god, лишние приваты и т. п. — это нарушает Minecraft Usage
       Guidelines и может привести к блокировке сервера Mojang.
       Цены и описания привилегий должны быть честными и видимыми до оплаты.
       Кейсы: донатный кейс содержит только косметику, а шансы каждого
       приза видны игроку до открытия (ПКМ по кейсу в /cases) — оставьте
       так. Если будете продавать ключи, укажите шансы и на странице
       магазина. В некоторых странах платные «лутбоксы» отдельно
       регулируются или запрещены (например, Бельгия) — проверьте законы
       страны, где принимаете оплату. Не добавляйте в донатный кейс
       предметы, деньги или ключи кейсов с игровыми предметами.
       Приём денег — это предпринимательская деятельность: уточните
       налоговые и юридические вопросы (самозанятость/ИП, оферта, возвраты)
       для вашей страны.

ПО ЖЕЛАНИЮ
---------------------------------------------------------------------
[ ] 9. Название и описание. server.properties → motd (строка в формате
       \uXXXX, проще всего изменить через сайт-генератор MOTD или написать
       латиницей); plugins/TAB/config.yml (шапка, скорборд);
       plugins/Essentials/motd.txt; plugins/Essentials/rules.txt.
       Голограммы на спавне содержат слово ClinderGrief — заменить можно командой
       (стоя рядом): /minecraft:kill @e[type=text_display,distance=..3]
       и созданием новой через /summon text_display (или оставить как есть).

[ ] 10. Контакты администрации (Discord/VK/Telegram) — добавьте в
       plugins/Essentials/motd.txt и rules.txt.

[ ] 11. Резервные копии — запускайте backup.bat регулярно (лучше при
       остановленном сервере) и храните копии на другом диске/в облаке.

[ ] 12. Предгенерация мира (меньше лагов при исследовании):
       в консоли  chunky radius 3000  и  chunky start  (займёт время и
       несколько ГБ места). Не обязательно.

[ ] 13. Белый список (закрытый сервер для друзей):
       whitelist on, whitelist add Ник.

[ ] 14. Скины NPC. Сейчас NPC — жители (скины не нужны). Чтобы сделать NPC
       игроком со скином: /npc type <имя> PLAYER и /npc skin <имя> <ник>.
       Для быстрой загрузки скинов можно указать mineskin_api_key
       (бесплатный аккаунт https://mineskin.org) в plugins/FancyNpcs/config.yml.

[ ] 15. Обновления. Paper 1.21.11 больше не получает исправлений
       (поддержка завершена 15.06.2026). Для долгой работы публичного
       сервера рассмотрите переход на актуальную версию Paper и
       соответствующие версии плагинов (сделайте резервную копию заранее).

[ ] 16. РЕЖИМ ВХОДА: ЛИЦЕНЗИЯ + ПИРАТКА (решите сами).
       По вашему запросу сборка настроена с регистрацией на Velocity
       (LimboAuth): Velocity работает в online-mode=false, поэтому зайти
       могут и игроки без лицензии — после /reg и /login. Лицензионные
       игроки входят без пароля, их ники с пиратки занять нельзя.
       Учтите: Mojang не поддерживает offline-mode, а игра без купленной
       лицензии противоречит EULA Minecraft. Ответственность за этот
       выбор — на владельце сервера.
       Чтобы пускать ТОЛЬКО лицензию: в velocity/velocity.toml поставьте
       online-mode = true и перезапустите (регистрация тогда не нужна:
       LimboAuth будет впускать всех автоматически).
       Администраторам обязательно: включите себе /2fa enable <пароль>.

[ ] 17. Секрет связи Velocity ↔ Paper создаётся сам при первом запуске
       (velocity/forwarding.secret = proxies.velocity.secret в
       config/paper-global.yml). Никому его не показывайте. Если копируете
       сервер на хостинг — переносите папку целиком.

[ ] 18. Античит ClinderAC. Первые дни читайте
       plugins/ClinderAC/violations.log. Если честных игроков с плохим
       интернетом откатывает — поднимите alert-vl/kick-vl нужной проверки
       или выключите её (enabled: false) в plugins/ClinderAC/config.yml,
       затем ac reload. Автобан можно включить через punish-command и
       punish-vl (по умолчанию выключен — лучше решать вручную по ac info).
       Персоналу для работы без проверок: lp user Ник permission set
       clinderac.bypass true.
