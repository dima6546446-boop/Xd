2. ТРЕБОВАНИЯ
---------------------------------------------------------------------
  * Windows 10 или 11, 64-бит (для start.bat). Linux/macOS — start.sh.
  * Оперативная память: сервер по умолчанию берёт до 4 ГБ, на компьютере
    должно быть хотя бы 8 ГБ. Изменить: строки MIN_RAM / MAX_RAM в начале
    start.bat (открыть «Блокнотом»).
  * Java 21+ (64-бит). Если её нет — start.bat предложит скачать
    Eclipse Temurin JRE 21 (adoptium.net) в папку runtime сборки,
    с проверкой контрольной суммы SHA-256. В систему ничего не ставится.
  * Интернет при первом запуске: Paper скачивает файлы игры с серверов
    Mojang и библиотеки (≈150 МБ), плагины — свои библиотеки.
  * Свободное место: от 2 ГБ (мир растёт по мере игры).

3. УСТАНОВКА И ПЕРВЫЙ ЗАПУСК
---------------------------------------------------------------------
 1) Распакуйте архив целиком, например в C:\MineRus
    (лучше путь без кириллицы и пробелов — так надёжнее).
 2) Дважды щёлкните start.bat.
 3) Если Java 21 не найдена — нажмите Y, чтобы скачать её автоматически
    (или установите вручную: https://adoptium.net/temurin/releases/?version=21).
 4) Скрипт покажет ссылку на EULA Minecraft (https://aka.ms/MinecraftEULA).
    Прочитайте и нажмите Y, если принимаете. Это делает ТОЛЬКО владелец
    сервера — в архиве EULA намеренно не принята (eula=false).
 5) Первый запуск длится 1–3 минуты (загрузка файлов, подготовка плагинов).
    Сервер готов, когда в окне появится строка:
        Done (…s)! For help, type "help"
 6) Остановить сервер: введите в окне консоли  stop  и нажмите Enter.
    Не закрывайте окно крестиком — мир может не сохраниться.
    После остановки скрипт предложит: R — перезапустить, Q — выйти.

Windows может спросить разрешение для Java в брандмауэре — разрешите
доступ в частных сетях (и в общедоступных, если друзья подключаются
через интернет).

4. ПОДКЛЮЧЕНИЕ К СЕРВЕРУ
---------------------------------------------------------------------
  * С этого же компьютера: в Minecraft 1.21.11 → Сетевая игра →
    Добавить сервер → адрес  localhost
  * В локальной сети: адрес — локальный IP компьютера (команда ipconfig,
    строка IPv4, например 192.168.1.10).
  * Через интернет: нужен проброс порта 25565 (TCP) на роутере и внешний
    («белый») IP либо VPN/туннель. Подробно — MANUAL_STEPS_RU.txt.

Сервер работает в режиме online-mode=true: заходить могут только
игроки с лицензионным аккаунтом Minecraft Java Edition.
Версия клиента — 1.21.11.

5. ВЫДАЧА ПРАВ И ПРИВИЛЕГИЙ
---------------------------------------------------------------------
Права выдаются через LuckPerms. Команды вводятся в консоль сервера
(окно start.bat) без «/» или в игре с «/» (если у вас уже есть права).

Сделать себя администратором (обязательно после первого входа):
    lp user ВашНик parent set admin

Группы (уже созданы и настроены):
  Группа    Префикс        Кто это
  default   (серый ник)    все игроки
  vip       [VIP]          привилегия, только косметика
  premium   [Premium]      привилегия, только косметика
  elite     [Элита]        привилегия, только косметика
  helper    [Хелпер]       младший модератор: мут, кик, тюрьма,
                           временный бан (до 7 дней), просмотр журнала
  moder     [Модератор]    + бан, ваниш, invsee, откат CoreProtect,
                           телепорт, полёт, удаление приватов
  admin     [Админ]        все права (*)

Примеры:
    lp user Ник parent set moder          — назначить модератором
    lp user Ник parent add vip            — выдать VIP навсегда
    lp user Ник parent addtemp vip 30d    — выдать VIP на 30 дней
    lp user Ник parent remove vip         — забрать VIP
    lp user Ник info                      — посмотреть группы игрока
    lp editor                             — удобный веб-редактор прав

Что дают привилегии (только косметика — разрешено правилами Minecraft):
  VIP:     префикс, цветной чат (&a, &b …), /nick, /hat
  Premium: + жирный/курсив в чате, цветной ник, /ptime, /pweather
  Элита:   + HEX-цвета в чате и нике, цветные таблички
Привилегии НЕ дают предметов, денег, полёта, бессмертия, лишних приватов
и других игровых преимуществ — продажа таких преимуществ запрещена
Правилами использования Minecraft (Minecraft Usage Guidelines / EULA).

Все команды создания групп сохранены в файле
plugins/LuckPerms/MineRus-luckperms-setup.txt — по нему можно
восстановить группы в чистой базе.

6. ЧТО УМЕЕТ СЕРВЕР (ДЛЯ ИГРОКОВ)
---------------------------------------------------------------------
Спавн — летающий остров над точкой 0,0 (Y=101): фонтан, площадь,
4 павильона с NPC, голограммы-подсказки. Новички появляются на спавне
и получают стартовый набор (каменные инструменты, еда, факелы, брёвна,
золотая лопата для привата и палка для просмотра приватов).
На спавне нельзя ломать/строить, PvP, урон от падения и мобы отключены.

NPC на спавне (нажмите на жителя):
  Торговец   → магазин сервера (/shop)
  Скупщик    → скупщик ресурсов (/buyer)
  Привилегии → описание привилегий (/donate)
  Гид        → главное меню (/menu)

Основные команды:
  /menu                 главное меню (всё ниже доступно и через него)
  /shop  /buyer         магазин сервера / скупщик
  /tpr  (или /rtp)      случайная телепортация в дикий мир (300–3000 блоков)
  /spawn                на спавн
  /sethome [имя], /home [имя], /delhome   — до 3 домов
  /tpa Ник, /tpahere Ник, /tpaccept, /tpdeny
  /back                 вернуться на прошлое место (и после смерти)
  /balance, /baltop, /pay Ник сумма
  /sell hand, /sell <предмет>, /worth   — продажа скупщику и цены
  /kit start (один раз), /kit food (раз в сутки)
  /msg Ник текст, /r, /mail, /ignore
  /rules, /helpop текст (вызвать модератора)

Экономика: стартовый баланс 500$. Деньги зарабатываются продажей
ресурсов скупщику и торговлей с игроками. Цены продажи всегда ниже цен
покупки — бесконечно перепродавать нельзя.

Приваты (GriefPrevention):
  * Первый сундук автоматически приватит небольшую область вокруг.
  * Золотая лопата: ПКМ по одному углу, затем по противоположному.
  * Палка (ПКМ) показывает границы приватов.
  * Старт — 400 блоков привата, +150 за каждый час игры.
  * /trust Ник, /untrust Ник, /claimslist, /abandonclaim,
    /buyclaimblocks кол-во (5$ за блок), /sellclaimblocks.

Магазины игроков (QuickShop): поставьте сундук, ударьте его (ЛКМ)
предметом-товаром, введите в чат цену за 1 шт. Покупатель нажимает на
сундук и вводит количество. /qs sell, /qs buy, /qs price, /qs remove.

7. МОДЕРАЦИЯ И АДМИНИСТРИРОВАНИЕ
---------------------------------------------------------------------
  mute Ник 30m причина        — заглушить (helper+)
  kick Ник причина            — выгнать (helper+)
  jail Ник tyurma 10m         — в тюрьму (камера под островом спавна)
  unjail Ник
  tempban Ник 1d причина      — временный бан (helper — до 7 дней)
  ban Ник причина, unban Ник  — бан (moder+)
  vanish, invsee Ник, socialspy, tp Ник (moder+)
  co i                        — инспектор: ЛКМ/ПКМ по блоку показывает,
                                кто его ставил/ломал (helper+)
  co lookup u:Ник t:1d        — поиск по журналу
  co rollback u:Ник t:1h r:30 — откатить действия гриферa (moder+)
  ignoreclaims                — игнорировать приваты (moder+)
  deleteclaim / deleteallclaims Ник — удалить приват(ы) (moder+)
  adjustbonusclaimblocks Ник 1000   — выдать блоки привата (moder+)
  eco give Ник 100            — выдать деньги (admin)
  rg info spawn               — регион спавна WorldGuard
  chunky radius 3000, chunky start — предгенерация мира (admin, по желанию)
  save-all                    — сохранить мир
  backup.bat                  — резервная копия (лучше при остановленном сервере)

9. ПРОВЕРКА КЛЮЧЕВЫХ ФУНКЦИЙ (ЧЕК-ЛИСТ ДЛЯ ВЛАДЕЛЬЦА)
---------------------------------------------------------------------
После первого запуска зайдите на сервер и проверьте:
  [ ] Вы появились на острове спавна у фонтана, в чате русское приветствие,
      в инвентаре стартовый набор, сверху справа — скорборд MineRus.
  [ ] /balance показывает 500$.
  [ ] /menu открывает меню; «Магазин» → категория → покупка списывает деньги
      и выдаёт предметы.
  [ ] /buyer → «Руды и минералы» → продажа железа начисляет деньги.
  [ ] Нажатие на жителей-NPC открывает соответствующие меню.
  [ ] Попытка сломать блок на спавне: «Это действие запрещено на спавне.»
  [ ] /tpr переносит в дикий мир; там поставьте сундук — появится
      сообщение о привате; /claimslist показывает приват.
  [ ] Создайте магазин из сундука (см. раздел 6).
  [ ] lp user ВашНик parent set admin → префикс [Админ] в чате и TAB.
  [ ] mute/jail/unjail на тестовом аккаунте (или на себе).
  [ ] co i — инспектор показывает историю блоков.
  [ ] В консоли при запуске нет строк ERROR (предупреждения WARN о версии
      FancyNpcs, о «tax account» QuickShop и об устаревшей 1.21.11 — норма).

10. ЧТО ПРОВЕРЕНО ПРИ СБОРКЕ, ОГРАНИЧЕНИЯ
---------------------------------------------------------------------
Сборка запускалась на Linux (OpenJDK 21) с теми же параметрами JVM,
что в start.bat (через start.sh). Проверено:
  * все 15 плагинов загружаются без ошибок (ERROR в логе нет);
  * тестовые боты (клиент mineflayer, протокол 1.21.11) подключались и
    проверяли: точку спавна и стартовый набор, баланс, меню, покупку в
    магазине, продажу скупщику, NPC, TAB, защиту спавна, /tpr, /sethome,
    /home, авто-приват сундука, создание магазина QuickShop, мут, тюрьму,
    формат чата и префиксы, отказ в доступе к админ-командам;
  * все файлы плагинов скачаны с Modrinth/GitHub, контрольные суммы
    совпали с опубликованными (SOURCES.txt).
Для теста сервер временно запускался в режиме online-mode=false
(для ботов без лицензии); в архиве стоит online-mode=true.

Ограничения проверки:
  * start.bat не запускался на настоящей Windows (её не было в среде
    сборки). Логика скрипта (поиск Java в runtime\, разбор версии,
    проверка 64-bit, проверка EULA, команда запуска) проверена через
    cmd.exe из Wine; сама Java под Wine не работает, поэтому полный запуск
    именно через start.bat на Windows — пункт для проверки владельцем.
  * Загрузка Java через scripts\install-java.ps1 не запускалась
    (нет PowerShell в среде сборки); формат ответа API Adoptium и ссылка
    на архив JRE 21 проверены отдельно.
  * Вход с настоящего лицензионного клиента не проверялся.

11. ЧТО ОСТАЛОСЬ НА АНГЛИЙСКОМ
---------------------------------------------------------------------
Переведено на русский: EssentialsX (встроенный ru), QuickShop (встроенный
ru_RU), LuckPerms (перевод скачивается автоматически и показывается
по языку клиента игрока), WorldEdit (по языку клиента), Chunky (ru),
GriefPrevention (полный перевод в составе сборки), CoreProtect (полный
перевод в составе сборки), TAB (перевод в составе сборки), меню, NPC,
голограммы, MOTD, правила, сообщения Paper/Spigot.

Остались на английском (видят в основном администраторы):
  * WorldGuard — тексты зашиты в плагин (игроки видят только наши
    русские сообщения запрета и приветствия региона, а также
    «You don't have permission.» при попытке вызвать /rg).
  * FancyNpcs — сообщения команд /npc (только для админов).
  * PlaceholderAPI, Vault, DeluxeMenus — служебные сообщения админ-команд.
  * Консоль LuckPerms — на английском (у игроков — язык их клиента).
  * Часть подсказок /qs help без перевода в самом QuickShop.
  * Сообщения о достижениях и ванильные сообщения переводит сам клиент
    Minecraft (при русском языке игры — на русском).
